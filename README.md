# Каталог игр

Учебный проект по веб-разработке.

- **Студент:** Александр
- **Тема:** Каталог игр

## Описание
Приложение для учета личной библиотеки игр. Пользователь добавляет игры, выбирает платформу (PC, консоли), отмечает статус прохождения («в планах», «играю», «пройдено») и ставит личную оценку.

## Стек технологий
- React
- TypeScript
- Vite

## Требования
- Node.js (версия указана в файле .node-version)
- npm

## Запуск проекта
Из корня скачанного репозитория:
cd frontend
npm ci
npm run dev

## Проверка сборки
cd frontend
npm run build
npm run preview

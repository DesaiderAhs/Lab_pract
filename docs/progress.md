# Прогресс разработки

## Лабораторная работа 1: Старт проекта на React и TypeScript
- Выбрана тема: "Каталог игр".
- Развернут каркас React + TypeScript на Vite.
- Настроен начальный экран (заголовок, описание, заглушка списка).
- Настроена сборка и проверка типов.

### Шаги проверки:
1. cd frontend; npm run dev - запуск сервера разработки
2. cd frontend; npm run build - проверка типов и сборка в dist
3. cd frontend; npm run preview - локальный запуск готовой сборки
4. Проверка запуска из чистой копии репозитория через npm ci

## Лабораторная работа 2: Страницы и навигация
- Подключена библиотека React Router в декларативном режиме.
- Создана модель данных игры (типы TypeScript) и массив из 5 записей.
- Сделан компонент GameCard и общий layout приложения (AppLayout).
- Реализованы маршруты:
  - `/` -> редирект на `/games`
  - `/games` -> каталог игр
  - `/games/:id` -> детальная страница с поиском по id
  - `/games/new` -> заглушка создания записи
  - `*` -> 404 страница
- Обработаны случаи перехода на неизвестный URL и запроса несуществующего id.

## Лабораторная работа 3: Формы и локальное состояние
- Состояние игр поднято в компонент App (`useState`).
- Реализованы чистые неизменяемые операции CRUD:
  - Создание игры с генерацией id через `crypto.randomUUID()`.
  - Редактирование существующей записи по id.
  - Удаление игры с подтверждением через `window.confirm`.
- Разработана переиспользуемая форма `GameForm` с локальным черновиком и валидацией полей (название, жанр, оценка 1-10).
- Добавлена отмена редактирования без сохранения изменений.
- На странице каталога добавлен локальный фильтр по статусу игры со сбросом.
- В интерфейс добавлено уведомление о сеансовом режиме хранения данных в памяти.

# Прогресс разработки

## Лабораторная работа 1: Старт проекта на React и TypeScript
- Выбрана тема: "Каталог игр".
- Развернут каркас React + TypeScript на Vite.
- Настроен начальный экран (заголовок, описание, заглушка списка).
- Настроена сборка и проверка типов.

### Шаги проверки:
1. cd frontend; npm run dev - запуск сервера разработки
2. cd frontend; npm run build - проверка типов и сборка в dist
3. cd frontend; npm run preview - локальный запуск готовой сборки
4. Проверка запуска из чистой копии репозитория через npm ci
